# 一点点代购分杯助手

给南阳一点点奶茶代购用的分单工具：几百杯拉回来，靠编号快速对上订单。

## 流程

1. **接单即编号** — 每杯一个连续编号（001、002…），下单时就定死
2. **出杯贴号标** — 记号笔在杯盖写号，或打印 A4 不干胶杯贴
3. **按板块分箱** — 师院配送 / 理工学院配送 / 到店自提，一袋一组，袋外写编号范围
4. **报号秒核销** — 客户报手机后四位，查出编号直接拿

## 功能

- 截图识别下单：选客户发来的一点点小程序截图，自动认出品名与规格（杯型 / 冰 / 糖 / 加料）
- 三个配送板块下拉 + 顶部杯数统计
- 打印四种纸：门店下单表（含品类汇总）、写号清单、杯贴标签（A4 不干胶）、装箱单（按板块分组）
- 分发核销：输后四位 / 姓名 / 编号秒出结果，编号墙点选标记，进度条
- 备份：JSON 导入导出、CSV 导出

## 技术

单文件纯前端，`index.html`，无后端、无数据库、无依赖构建。数据存在浏览器 localStorage。
截图识别用 tesseract.js + chi_sim 语言包（首次使用需联网下载组件）。
